# Video merging

Call `merge_videos` with:

- `video_urls`: 2 to 100 items, in the order the user wants
- `transition`: `none`, `fade`, or `dissolve`

Preserve input order. Do not reorder clips. Use durable URLs from attachments or prior tool results.
